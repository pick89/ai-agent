# AI Bot Control

## Quick Commands:
```bash
# Start with swap (recommended - all models)
./run_bot.sh
./run_bot.sh swap

# Start without swap (light models only)
./run_bot.sh noswap

# Restart with swap
./restart_bot.sh
./restart_bot.sh swap

# Restart without swap
./restart_bot.sh noswap

# Check status
./restart_bot.sh status

# Stop bot
./restart_bot.sh stop
